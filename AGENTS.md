# UI and UX changes

- Use [Design with Intent’s Evaluate workflow](https://designwithintent.ai/skills/#evaluate) before changing a flow. Walk through the task, check that scope and feedback are clear, and prioritize the friction found.
- Use [Impeccable](https://impeccable.style/docs/improve-design) to refine the affected surface. Run its [detector](https://impeccable.style/docs/detector) on the changed UI, and review findings rather than treating the detector as a usability test.
- Review the workspace at desktop size first. Review the popup at its actual popup size; use a narrow workspace viewport only as a secondary check. With sample data, verify the main flow, keyboard focus, and relevant loading, empty, and error states. Report which checks were actually run.
